05 · JS Control Flow

Functions, conditionals & loops

Enter a score and run it — the function decides pass/fail, then a loop counts up to it.

flow.js
function checkScore(score) {
  if (score >= 60) {
    return "Pass";
  } else {
    return "Fail";
  }
}

for (let i = 1; i <= score; i += 20) {
  console.log("Progress:", i);
}
